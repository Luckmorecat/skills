Create or amend a self-contained work contract from the supplied conversation, decisions, or documents. Reuse settled intent and preserve existing approval, delegation, and identifiers.

Derive observable acceptance examples from agreed behavior. Inspect relevant code for current facts and verification commands; distinguish them from intended changes. Keep proposals and unverified assumptions separate from agreed decisions.

If writing the contract exposes a missing consequential choice or conflicting intent, surface the specific gap and affected work. Resolve it with the user before treating the contract as complete; reuse the rest of the settled context.

Use [CONTRACT-FORMAT.md](CONTRACT-FORMAT.md) to present and save the contract. Keep its detail proportional to the work. Return the absolute path.
